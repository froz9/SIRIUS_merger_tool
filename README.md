# SIRIUS merger tool
I developed this app to merge the main output files from SIRIUS. It will help you to organize and visualize your data. It uses "canopus_structure_summary" and "structure identifications" as inputs. Both files need to be in .TSV format, and it uses diverse R functions to visualize your data.
Please visit: https://5bptzm-alan-hernandez.shinyapps.io/SIRIUS_merger_tool/ to try it.
